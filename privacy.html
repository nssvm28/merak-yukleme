Privacy Policy — Merak Yukleme

Last updated: 24 November 2026

Who uses this tool

Merak Yukleme is a personal tool run on the owner's own computer. Its only user is the owner of the YouTube channel "Merak Makinesi". It does not have public users and does not collect data from anyone else.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed

  • The OAuth token for the owner's own YouTube channel, granted with the scopes youtube.upload and youtube.
  • Basic channel information (channel ID and title), used only to confirm the correct channel is connected.
  • The owner's own video files and their metadata (title, description, tags, thumbnail, publish time), which are sent to YouTube when uploading.

How data is used and stored

Data is used only to upload and schedule the owner's own videos. The OAuth token is stored locally on the owner's computer and is never sent anywhere except to Google. No data is sold, shared with third parties, used for advertising, or stored on any server. No cookies or tracking are used.

Revoking access

Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. Deleting the local token file removes all stored data.
